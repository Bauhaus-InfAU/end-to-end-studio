# References

The drawings the studio's look comes from. Egor puts them here, the same ones as on the course board. `drawing-graphics` reads the images in this folder and writes the standard all drawing skills follow. Change the images and the whole entry changes its look; nothing else has to change.

PNG or JPG, one drawing per file, named after its office and drawing, e.g. `office-name_masterplan.png`.

## The winners

Since 04.11.2026 the three Europan 18 winners of this site are the main references, in `winners/`. The folder isn't in git, because the boards are other people's work. Get it as a zip from Moodle and unpack it here, so you have `competition/references/winners/1_prize_zam-wachsn/` and the other two.

Each entry has:
- its three boards, `board-1.jpg` to `board-3.jpg`
- the same boards with the stickies of 04.11. numbered on them, `board-N_marked.jpg` (see `competition/feedback/2026-11-04_run-10/`)
- one file per drawing
