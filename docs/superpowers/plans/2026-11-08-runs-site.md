# Runs Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static public site (Model, Panels, Loop, All runs) built from the studio's run folders by one Python script and published to a `gh-pages` branch by a second, with the Europan 18 winners kept off it.

**Architecture:** `runs_site.py` reads every run folder, the project inputs and the skills' `Reads:` lines at each run's commit, and writes plain JSON, JPGs and a fixed set of web files into `<proposals>/site/`. The web files are vanilla JS modules on one shell (`app.js`) that owns routing, data loading and the shared timeline; each page is one file that only reads the JSON contract below. `publish_site.py` merges with what is already published, checks the build is safe, asks, and force-pushes one fresh commit to `gh-pages`.

**Tech Stack:** Python 3.12 with Pillow only (already used by `side_by_side.py`); pytest; vanilla JS; deck.gl 9.0.38 from jsdelivr (same URL and SRI hash as `preview.html`); Inter and JetBrains Mono from Google Fonts.

**Spec:** `docs/superpowers/specs/2026-11-08-runs-site-design.md`

**Name change from the spec:** the spec says `site.py` and `publish.py`. They are `runs_site.py` and `publish_site.py`, with their modules in a package `runsite/`, because `tests/conftest.py` puts the scripts folder on `sys.path` and a module called `site` would shadow Python's own.

## Global Constraints

- Everything lives in `plugins/studio/skills/competition-proposal/scripts/`. No script names this repo's site, competition, layers or paths; every path is an argument (CLAUDE.md).
- No new Python dependency beyond Pillow. No build step for the web files (no npm).
- External scripts only from `cdn.jsdelivr.net` with the exact SRI hash: `https://cdn.jsdelivr.net/npm/deck.gl@9.0.38/dist.min.js`, `integrity="sha512-R306Iwv466NdydETeKnjn2TaosUQ3t++lw5u/E7kHefLMFSSJtFVHXbU3xpfpf0QX86kuAf6yuY+S9kcp7J+zw=="`. Fonts only from Google Fonts.
- Look: the approved mockup `.superpowers/brainstorm/18470-1794091911/content/three-pages.html`. Tokens, copied verbatim into `app.css`: `--bg:#fafaf9;--paper:#fff;--ink:#141414;--ink2:#4a4a4a;--muted:#6f6e6a;--hair:#e8e7e4;--hair2:#f1f0ee;--opus:#141414;--sonnet:#b9b8b3;--sel:#2f62ff;--issue:#e5484d`. One accent (`--sel`) for selection, `--issue` only for problems, no other colours outside map layers.
- Never copy into the site: any path with a part named `references`, `winners` or `.compare`, any `.env`, any file outside the allow list (Task 2). Never show winners' names (Task 2's `scrub`).
- Coordinates rounded to 6 decimals (reuse `preview.load`).

## Review Focus

1. **A run that crosses midnight** (run-10: 23:29 to 00:36): times after midnight must come after, not before, the start. → `test_log_crosses_midnight` in Task 1.
2. **Old or thin runs** (run-1 to run-5 have no `layout.json`, older log forms, `usage.csv` instead of `cost.csv`; another person's run has only git files): every reader returns empty values, never raises, and every page shows what exists. → `test_read_run_minimal` in Task 3 and the run-1 check in Tasks 7 to 10.
3. **A drawing in `layout.json` whose file is missing locally or is an SVG without a PNG beside it**: the item still gets an image, cut from the panel PNG. → `test_item_image_falls_back_to_panel_crop` in Task 5.
4. **Winner names in other spellings**: different case, hyphens for spaces, inside a file path (`version.md` lists `3_special-mention_copper-moth`). → `test_scrub_variants` in Task 2.
5. **Publishing from a computer that has less of a run than the site already shows**: the published run is kept. → `test_merge_keeps_richer_published_run` in Task 11.

## Data contract (what Tasks 6 to 10 read)

Built site, `<proposals>/site/`:

```
index.html  app.css  app.js  timeline.js  model.js  panels.js  loop.js  dash.js  .nojekyll
build.json                     {"built": "2026-11-08T14:02", "references": true, "commit": "cf97c2e"}
data/index.json                Index
data/runs/<key>.json           Run
data/geo/shared.json           Geo   (project: site, climate, analysis)
data/geo/<key>.json            Geo   (the run's own GeoJSON, by skill folder)
img/<key>/panel-<n>.jpg
img/<key>/<item-id>.jpg
```

```text
Index = { project: {name: str}, runs: [RunCard], ledger: [LedgerRow], skills_all: [str] }
RunCard = { key, label, title, date, kind: "run"|"variant", usd|null, minutes|null,
            verdict|null, items: [placed, required]|null, n_skills, has: {geo, panels, layout, loop} }
LedgerRow = { error, kind, runs: {label: "x"|"q"}, fix: {after: label, what, held: bool}|null }

Run = RunCard + {
  start: "HH:MM"|null, end: "HH:MM"|null, commit|null, new_in_run: str|null,
  usd_by_skill: {skill: usd}, usd_by_model: {opus, sonnet}, usd_lead|null,
  headline: {homes, gfa_m2, new_buildings, green_ha}  (any may be null),
  jury: {verdict|null, summary_md|null, links: {skill_or_item_id: [str]}},
  skills: { <skill>: { model: "opus"|"sonnet"|null, usd|null,
             runs: [{kind: "first"|"second"|"rerun", t0, t1, line}],   // t in minutes from run start
             summary_md|null, unsure|null, fixes: [str], issues: [{severity, issue, fix}],
             red: bool } },
  events: [{t, kind: "check"|"lead"|"note", text}],     // frames.py, cost.py, side_by_side.py lines
  panels: [{n, img, w_px, h_px, items: [Item]}],
  open_problems_md|null, handed_on_md|null,
  loop: Loop|null
}
Item = { id, file, skill, caption|null, shows|null, scale|null, x, y, w, h,   // fractions 0..1 of the panel
         img, flagged: str|null }                                             // flagged: the frames.py words naming it
Loop = { commit, nodes: [{id, kind: "input"|"skill"|"lead", topic|null, model|null,
                          reads: [id], reads_end: [id]}] }
Geo = { <group>: { <layer>: FeatureCollection } }
```

Rules the builder follows (Tasks 3 to 5):
- `label` is the folder name after the date (`2026-11-07_run-11` → `run-11`); `key` is the folder name.
- A skill is `red` when it has `fixes`, `issues`, or an Item of it is `flagged`. Nothing else makes it red.
- An Item's `skill` is the `by` of the `required` entry with the same `id`, else the first part of `file`.

SK = {"climate", "programme", "narrative", "massing", "site-section", "analysis", "plans", "isometric"}

- [ ] **Step 3: Implement `parse_log` in `runsite/log.py`**

Per line: strip a leading `- `; take the first `HH:MM` as the time (add 1440 while it falls more than 600 minutes before the previous time). A line is a **start** when it matches `start(?:ed)?(?: reruns)?:?` (also `Round N started HH:MM:`); split the rest on commas; per part, the skill is the first known skill name in it; the kind is `rerun` if the line says `reruns`, `second` if the part says `second` or `(end)`, else `first`. A line is a **done** when, after the time, it matches `^(?P<skill>[a-z-]+)(?: \([^)]*\))?(?: (second run|second|rerun|redraw))? done`; `rerun`/`redraw` → `rerun`, `second`/`second run`/`(end)` in the parentheses → `second`, else `first`. A done closes the latest open start of the same skill and kind; with no open start, `t0` is the latest start line's time before it, else 0. A line naming `frames.py` or `cost.py` is an event of kind `check`; `side_by_side.py` is `lead`. Everything else is ignored. `line` is the text after `done:` (or after `done`), trimmed to 200 characters.
