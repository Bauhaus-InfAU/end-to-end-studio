# Lean Studio Run Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One full studio run on the Regensburg brief costs about $12 at API prices (one Pro 5-hour window) and is at least as good as run-3.

**Architecture:** The lead skill `competition-proposal` starts every skill as a lean `studio-helper` agent from the `studio` plugin, on the model the skill names (Sonnet by default). The brief is read once into a checklist by a new `brief-reader` skill. The most expensive skills start from a script in their own folder instead of writing one. A cost script reads the run's transcripts and writes `cost.csv`, so every lever is measured.

**Tech Stack:** Claude Code plugins (skills, agents), Python 3.11+ with shapely and pyproj, pytest, Git Bash or PowerShell on Windows.

**Spec:** `docs/superpowers/specs/2026-11-02-lean-run-design.md`

- Unslop rules for any text students read. No middle dots.

## Review Focus

1. **A transcript with repeated message ids** (Claude Code writes one line per content block, all with the same id and usage). The cost script counts each id once; test in Task 1.
2. **A skill with no `Model:` line.** It runs on Sonnet, never on the session's model by accident; checked by the dry run in Task 4.
3. **A brief that has no checklist yet, or a second version on the same brief.** `brief-reader` runs only when `checklist.md` is missing next to the brief; the dry run in Task 4 checks both cases.
4. **A script run on another site** (another `site.geojson`, a config without one of the brief values). It stops with the name of the missing value, it doesn't fall back to a Regensburg number; tested in Tasks 6 to 8 with a config missing one key.
5. **Paths with spaces and Windows backslashes** in the proposal folder. Every script takes paths as arguments and is tested once with a folder name containing a space.
