# Utilities

Tools that turn a project's files into something the other skills can read. They serve every topic and decide nothing about the design.

- Input: any file the user names, mostly PDF.
- Output: next to the file it came from, so every version of a proposal reads the same. `pdf-to-md` writes Markdown with page markers, so every number can be cited with its file and page, plus the pictures and the vector plans in it.
- A new skill here: anything that converts or cleans a source, such as a DWG to GeoJSON or a spreadsheet to CSV.
